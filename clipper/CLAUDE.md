# Twitch Clipper: контекст для работы над проектом

Отдельный проект в папке `clipper/` репозитория tg-lead-radar (с самим радаром не
связан). Описание и запуск - в `README.md`.

## Состояние

Проверено только тестами на синтетике (`pytest`, поддельный поток из ffmpeg,
поддельные Telegram и API нейросети). На момент написания ни разу не запускалось:

- против настоящего Twitch (streamlink, чат по IRC, название категории GTA 6);
- с настоящим Telegram (в том числе замена видео в сообщении кнопками подрезки);
- с настоящим API DeepSeek или Claude (форма запроса DeepSeek написана по
  поиску, страницы документации из облачной песочницы были недоступны);
- расшифровка речи (faster-whisper);
- на Windows.

Первый шаг на машине с доступом к Twitch:
`python -m twitch_clipper.tryout <логин> --minutes 30` и разбор того, что сломается.

## Договорённости с владельцем

- Нарезаем пока только GTA 6 (`GAMES=Grand Theft Auto VI`).
- Нейросеть для оценки - DeepSeek.
- Следующая задача после первого живого прогона - конвейер «кандидаты ->
  человек выбирает кнопкой -> бот накладывает субтитры и присылает готовый
  файл». Субтитры: faster-whisper с таймкодами слов -> файл .ass -> вжигание
  через ffmpeg.
- Пороги детектора (`CHAT_MULT`, `CHAT_MIN_MESSAGES`) стоят наугад, настраиваются
  по живым стримам.

## Правила

- Тесты не ходят в сеть. Всё, что зависит от Twitch, Telegram или API,
  подменяется (`source_factory`, `probe_factory`, `FakeSession`, локальный
  HTTP-сервер).
- Перед коммитом: `ruff check .` из корня репозитория и `pytest` из `clipper/`.
