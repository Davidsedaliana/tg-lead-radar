# Twitch Clipper

Telegram-бот, который сам делает нарезки со стримов Twitch: пишет эфир, следит за
чатом и, когда чат «взрывается», вырезает этот момент и присылает его в группу.

```
Twitch ──> streamlink ──> ffmpeg: кольцевой буфер, последние 4 минуты эфира
  │
  └─ чат (IRC, анонимно) ──> детектор: сообщений в 3+ раза больше обычного
                                   │
        30 с до всплеска + 15 с после ──> вертикальный клип 9:16
                                   │
        кадры + чат (+ расшифровка речи) ──> нейросеть: оценка 1-10
                                   │
                  Telegram: видео, подпись, кнопки 👍 / 👎
```

Подпись к клипу:

```
🎬 buster · 18.11 14:35 · 😂 смешно · чат x3.0 · 🔊 x2.8
🤖 8/10: Яркие эмоции, оглушительный смех чата, забавный провал
💬 дресня
💬 ПХАХАХАХАХАХА
```

## Запуск на VPS (Ubuntu / Debian)

```bash
sudo apt update && sudo apt install -y ffmpeg python3-venv git
git clone <этот репозиторий> && cd tg-lead-radar/clipper
python3 -m venv .venv && .venv/bin/pip install -e .
cp .env.example .env
```

1. Создай бота у [@BotFather](https://t.me/BotFather), впиши токен в `BOT_TOKEN`.
2. Запусти `.venv/bin/python -m twitch_clipper`, добавь бота в группу для нарезок
   и напиши там `/start`. Бот ответит id чата: впиши его в `CHAT_ID`.
3. Перезапусти бота и добавь стримеров: `/add buster evelone192`.

Команды в чате:

| Команда | Что делает |
|---|---|
| `/list` | Список стримеров, кто в эфире и во что играет, кнопки «Резать / Не резать» |
| `/add логин` | Добавить стримера (можно несколько через пробел) |
| `/remove логин` | Убрать стримера |

Чтобы бот работал постоянно и поднимался после перезагрузки, заведи службу
`/etc/systemd/system/twitch-clipper.service` (пути поправь под себя):

```ini
[Unit]
Description=Twitch Clipper
After=network-online.target

[Service]
WorkingDirectory=/root/tg-lead-radar/clipper
ExecStart=/root/tg-lead-radar/clipper/.venv/bin/python -m twitch_clipper
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now twitch-clipper
journalctl -u twitch-clipper -f   # логи
```

## Только выбранные игры

`GAMES=Grand Theft Auto VI` в `.env`: бот пишет стрим, только пока стример в этой
категории Twitch. Проверка идёт перед началом записи и каждые 2 минуты во время
неё, так что если стример переключился на другую игру или «Общение», запись
останавливается, а при возврате в игру - продолжается.

- Название должно совпадать с категорией Twitch точно («Grand Theft Auto V» -
  это другая игра). Несколько игр перечисляются через запятую.
- В `/list` видно, во что стример играет: 🔴 - пишу, 🟡 - в эфире, но игра не из
  списка, ⚫ - не в эфире.
- Пустой `GAMES` - резать любые игры.

## Оценка нейросетью

GPU не нужен: оценку делает модель через API, сервер только отправляет ей три
кадра, сообщения чата и цифры всплеска.

- Впиши `ANTHROPIC_API_KEY` в `.env`. Без ключа бот шлёт все найденные моменты
  без оценки.
- `MIN_SCORE=6`: клипы с оценкой ниже не отправляются.
- `JUDGE_MODEL`: по умолчанию `claude-opus-5-5`. Для экономии можно поставить
  `claude-haiku-5-5`: она в десятки раз дешевле, но оценивает грубее.
- Расшифровка речи необязательна и тоже идёт на CPU:
  `.venv/bin/pip install -e ".[whisper]"` и `WHISPER_MODEL=small`.

## Какой нужен сервер

Запись идёт без перекодирования, поэтому процессор нагружает только рендер
клипов (по одному за раз). Главные расходы - трафик и диск:

- один стрим в 720p - около 3 Мбит/с входящего трафика, пока стример в эфире;
- буфер одного стрима на диске - около 100 МБ.

Для 5-10 стримеров хватит 2 vCPU, 2-4 ГБ памяти и 20 ГБ диска. Бери тариф с
безлимитным трафиком: 10 стримов по 5 часов в день - это примерно 70 ГБ в сутки.

## Настройка детектора

Все пороги лежат в `.env` (описаны в `.env.example`). Главные:

- `CHAT_MULT=3.0` - во сколько раз чат должен ускориться. Меньше значение -
  больше клипов и больше мусора.
- `CHAT_MIN_MESSAGES=15` - минимум сообщений за 10 секунд. Для маленьких
  стримеров уменьши, иначе всплески не будут засчитываться.
- `PRE_SECONDS` / `POST_SECONDS` - длина клипа до и после всплеска.
- `AUDIO_MIN_MULT` - требовать ещё и всплеск громкости (0 = не требовать).

## Разработка

```bash
.venv/bin/pip install -e ".[dev]"
.venv/bin/pytest          # часть тестов гоняет настоящий ffmpeg, около 1,5 минуты
ruff check .
```

Тесты не ходят в сеть: вместо Twitch подставляется синтетический поток из
ffmpeg, вместо Telegram и нейросети - заглушки.
