# TG Lead Radar

Личный радар фриланс-заказов в Telegram: слушает выбранные каналы и бизнес-чаты,
отбирает сообщения-заказы по ключевым словам и присылает в «Сохранённые
сообщения» карточку — источник, ссылка, текст заказа и **готовый черновик
отклика** под тип задачи. Остаётся поправить первую строку и отправить руками.

Радар **ничего не пишет в чаты** — только читает и уведомляет владельца.
Автоматическая отправка откликов не предусмотрена сознательно: это путь к бану
аккаунта и репутации спамера.

## Как это работает

```
каналы/чаты ──> Telethon (юзербот, только чтение)
                    │  фильтр: категории (fix/bot/ai/automation/python)
                    │  анти-фильтр: чужой самопиар, резюме
                    │  дедупликация: SQLite, переживает рестарты
                    ▼
        «Сохранённые сообщения»: карточка + черновик отклика
```

## Запуск

1. Получите `api_id` / `api_hash` на https://my.telegram.org (API development
   tools, платформа Desktop).
2. `cp .env.example .env` и впишите ключи. Список каналов — там же.
3. Установка и старт:

```bash
pip install -e ".[dev]"
python -m tg_lead_radar
```

Первый запуск спросит номер телефона и код подтверждения из Telegram — сессия
сохранится в `data/`, дальше вход автоматический.

Чтобы радар видел приватные чаты, аккаунт должен в них состоять.

## Настройка фильтров

Категории и стемы — в [filters.py](tg_lead_radar/filters.py) (стем матчится по
началу слова: «бот» ловит «бота/ботов», но не «работа»). Черновики откликов —
в [templates.py](tg_lead_radar/templates.py); при нескольких категориях
побеждает более специфичная (fix > bot > ai > automation > python).
